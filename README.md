# Java Practice Projects 🚀

A collection of console-based Java applications built as a 1st year CSIT student at ITER, Bhubaneswar, demonstrating core programming concepts, control flow, loops, and data structures.

---

## 📂 Projects Included

### 1. Phone Directory (`Phonedirectry.java`)
* **Description:** A contact book application that manages names and phone numbers using parallel lists and search-and-delete logic.
* **Key Concepts:** Parallel `ArrayList`s, scanner buffer management, case-insensitive lookups, and boolean flag validation.

### 2. ATM Simulator (`ATM.java`)
* **Description:** A banking console application simulating account balance checks, deposits, and withdrawals.
* **Key Concepts:** Conditional validation, arithmetic operations, and user state tracking.

### 3. Multiple-Choice Quiz Game (`quiz.java`)
* **Description:** An interactive trivia game that tracks scores based on user answers.
* **Key Concepts:** Arrays/ArrayLists for questions, conditional grading, and score accumulation.

### 4. Number Guessing Game (`guessnumber.java`)
* **Description:** A game where the user tries to guess a randomly generated number with feedback loops.
* **Key Concepts:** `Random` class, `while` loops, and conditional branching (`if-else`).

### 5. Rock-Paper-Scissors (`Rockpaperscissor.java`)
* **Description:** A classic text-based game playing against computer choices.
* **Key Concepts:** Random number generation, string comparisons, and game logic rules.
